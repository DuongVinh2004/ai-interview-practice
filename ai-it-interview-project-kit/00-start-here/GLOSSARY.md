# Glossary

| Thuật ngữ          | Định nghĩa                                                                  |
| ------------------ | --------------------------------------------------------------------------- |
| Blueprint          | Cấu hình một phiên: role, level, technology, competency, số câu và ngôn ngữ |
| Competency         | Năng lực cần đo như kiến thức, debugging, system design hoặc communication  |
| Question bank      | Kho câu hỏi chuẩn đã review                                                 |
| Generated question | Câu hỏi do AI tạo theo blueprint và constraints                             |
| Rubric             | Tiêu chí chấm điểm có mức độ và trọng số                                    |
| Evidence span      | Đoạn câu trả lời cụ thể hỗ trợ một nhận xét                                 |
| Golden set         | Bộ dữ liệu có nhãn chuyên gia dùng để eval                                  |
| Calibration        | Mức khớp giữa điểm AI và chuẩn chuyên gia                                   |
| Interview session  | Một lần luyện tập có state và snapshot cấu hình                             |
| Attempt            | Câu trả lời của candidate cho một câu hỏi                                   |
| Evaluation run     | Một lần chấm với model/prompt/rubric version cụ thể                         |
| Learning plan      | Danh sách mục tiêu và bài luyện dựa trên khoảng trống năng lực              |
| Decision gate      | Lựa chọn chưa được phép tự chốt                                             |
| Current state      | Khả năng có bằng chứng trong source/test hiện tại                           |
| Target state       | Khả năng project kit yêu cầu xây dựng                                       |
