# Delivery roadmap

## M0 — Baseline hardening

Verify repository claims, make CI truthful, add missing Prisma migrations, stabilize contracts/state machine, close auth/session/ownership gaps, require admin MFA, establish security scanning, telemetry, evidence templates, and local one-command verification.

## M1 — AI evaluation foundation

Replace length-based mock scoring with rubric/evidence schemas, version prompts/rubrics, create VI/EN golden and adversarial sets, build eval runner, calibrate reviewers, and implement honest degraded behavior. No external provider commitment yet.

## M2 — Provider and production integration

Run provider selection gate, implement the selected adapter, privacy review, quotas/cost controls, circuit breaker, load tests, and provider incident playbook.

## M3 — Candidate experience completeness

Complete taxonomy/blueprints, session recovery, results/learning paths, bilingual UX, WCAG 2.2 AA verification, exports/deletion, notifications, and analytics based on privacy-safe events.

## M4 — Content and platform operations

Content-review workflow, admin controls, audit search, usage controls, IaC, staged deployment, observability, SLOs, backup/restore, DR drills, security testing, and production readiness review.

## M5 — Controlled launch

Pilot cohort, support/incident readiness, legal notices, data-processing inventory, penetration test, performance/AI evaluation evidence, canary release, error-budget monitoring, and retrospective.

## Phase 2 gates

Voice, mentor collaboration, organization tenancy, payments, and new markets each require a fresh scope, privacy/threat-model delta, ADR, and acceptance evidence. Voice never implies emotion or personality inference.
