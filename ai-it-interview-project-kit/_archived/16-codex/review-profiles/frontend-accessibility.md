# Review profile: frontend/accessibility/bilingual

Activate for user-visible web flows, forms, interview room, results, learning path, admin UX, or shared components.

Check at minimum:

- affected flows support required VI/EN behavior;
- keyboard operation and focus order are usable;
- labels, validation errors and status updates are accessible;
- loading/empty/error/offline/degraded states are not omitted;
- color is not the sole status signal;
- affected semantics align with WCAG 2.2 AA requirements in the Project Kit;
- auth/ownership controls are not treated as client-only security;
- user-visible result/evaluation evidence remains understandable and traceable;
- critical E2E paths are updated where behavior changes.
