# Control Plane / Antigravity stop conditions

Stop and return a bounded diagnostic/decision packet when any of these conditions occurs:

- The repository/branch is not the official `DuongVinh2004/ai-interview-practice` source or live baseline cannot be verified.
- Dirty/untracked user work overlaps the task or a destructive/rewrite Git operation would be needed to continue.
- A deferred gate is reached: AI provider/model, cloud platform, payment, voice/recording, organization tenancy, new market, hiring integration, or another explicit decision in the register.
- Credentials, legal approval, provider terms, production data, external messaging, push/PR/deploy, Jira write, or cloud mutation lacks explicit authorization.
- A migration can destroy or irreversibly transform data without verified backup/restore and an approved sequence.
- Tests/evidence reveal cross-user leakage, MFA/admin bypass, secret exposure, unsafe AI authority failure, discriminatory/protected-trait behavior, material unsupported scoring, or data loss/duplication.
- Requirements, approved decisions, contracts, or live repository evidence materially contradict each other; record the conflict instead of choosing silently.
- Verification cannot run in the available environment and no safe equivalent can establish the required evidence.
- Antigravity repeatedly attempts to weaken/disable tests, assertions, lint/security rules, or acceptance criteria to obtain PASS.
- Three bounded correction attempts fail to resolve the same material defect, or the correction loop is introducing new critical/high defect classes faster than it resolves the original one.
- The Control Plane root-cause hypothesis remains low-confidence and the next safe step is evidence gathering rather than another speculative edit.
- Continuing would require scope expansion into a different task/epic without an explicit replan.

Safe read-only inspection, local tests, synthetic fixtures, reversible task-scoped edits, and documentation are allowed only within the user's granted scope.

When stopping, report:

```text
STOP_REASON:
TASK:
LAST_VERIFIED_BASELINE:
VALIDATED_FACTS:
UNRESOLVED_UNKNOWN:
RISK:
CORRECTION_ATTEMPTS:
SAFE_OPTIONS:
RECOMMENDED_DECISION_OR_NEXT_VERIFY:
```

Use `16-codex/FAILURE-AND-ESCALATION.md` for convergence rules. Stopping is preferred to inventing evidence or silently crossing an authorization/decision boundary.
