# Product modes

| Mode | Phase | Input | Output | Ghi chú |
|---|---|---|---|---|
| Quick practice | MVP | Một competency | 3–5 câu + feedback | Không ảnh hưởng progress chính nếu user chọn sandbox |
| Full interview | MVP | Role, level, stack, language | Session 8–12 câu + report | Luồng chuẩn |
| Focused remediation | MVP | Weak competency | Bài luyện ngắn + learning task | Sinh từ lịch sử |
| Voice interview | Phase 2 | Audio | Transcript + rubric feedback | Không suy luận cảm xúc |
| Mentor review | Phase 2 | User share | Read-only report | Link hết hạn và revoke được |

Mọi mode dùng chung taxonomy, rubric version, session ownership và evaluation audit.
