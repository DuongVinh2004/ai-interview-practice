# Critical user flows

## First interview

Register -> verify/sign in -> choose goal -> choose role/level/stack/language -> preview blueprint -> create session -> wait/resume generation -> interview -> review before submit -> evaluation progress -> result -> learning task.

## Resume safely

User reload -> fetch owned session -> render current state -> restore saved answers -> show retry/action phù hợp -> không tạo session/job mới ngoài ý muốn.

## Review result

Summary -> competency breakdown -> từng câu -> evidence + feedback -> limitation -> retry/focused practice -> report issue/re-evaluation.

## Delete data

Privacy settings -> explain impact -> step-up authentication -> request deletion -> status tracking -> completion evidence hoặc legal retention exception.

## Admin MFA

Admin sign in -> forced enrollment -> verify TOTP -> receive recovery codes once -> access admin -> step-up for sensitive action.
