# Learning path

Learning plan được tạo từ nhiều session, không từ một điểm đơn lẻ.

## Thành phần

- Competency profile theo rubric version.
- Weakness có minimum evidence count.
- Goal, activity, resource và target date.
- Review cadence và completion state.
- Link tới câu hỏi/attempt làm bằng chứng.

## Quy tắc

- Không so sánh điểm giữa rubric version khác nhau nếu chưa normalize.
- Recommendation phải giải thích vì sao được đề xuất.
- User có thể dismiss hoặc chỉnh mục tiêu.
- Resource bên ngoài phải có allowlist hoặc moderation.
- Không suy luận khả năng nghề nghiệp dài hạn từ dữ liệu luyện tập hạn chế.
