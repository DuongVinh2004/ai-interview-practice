# Question taxonomy

## Dimensions

- **Job role (13 canonical roles)**:
  - _Software Engineering_: Frontend Engineer, Backend Engineer, Full-Stack Engineer, Mobile App Engineer, Embedded & IoT Engineer.
  - _Data & AI_: AI / Machine Learning Engineer, Data Engineer, Data Scientist & Analyst.
  - _Cloud, Infrastructure & Security_: DevOps & Platform Engineer, Cloud & Solutions Architect, Security & DevSecOps Engineer.
  - _Quality & Leadership_: QA & Automation Test Engineer, Tech Lead & Engineering Manager.
- **Level**: Fresher, Junior, Mid-Level, Senior (and Staff/Principal mappings).
- **Technology catalog (48 core & popular technologies across 8 categories)**:
  - _Languages_: TypeScript, JavaScript, Python, Java, Go, C#, C++, Rust, PHP, Swift, Kotlin.
  - _Frontend_: React, Next.js, Vue.js, Angular, Tailwind CSS, HTML5 & CSS3.
  - _Mobile_: Flutter, React Native, iOS Swift, Android Kotlin.
  - _Backend_: Node.js, NestJS, Express.js, Spring Boot, Django, FastAPI, ASP.NET Core, Gin/GORM, Laravel.
  - _Databases_: PostgreSQL, MySQL, MongoDB, Redis, Elasticsearch, Cassandra, DynamoDB.
  - _API & Messaging_: GraphQL, gRPC, RESTful API, Apache Kafka, RabbitMQ, WebSocket.
  - _Cloud & DevOps_: Docker, Kubernetes, AWS, GCP, Azure, Terraform, CI/CD GitHub Actions, Linux Systems.
  - _AI, Data & QA_: PyTorch, TensorFlow, LangChain & RAG, Pandas & NumPy, Spark, Playwright, Cypress, Selenium, Jest/Vitest, OWASP Security, k6/JMeter.
- **Competency (5 core areas)**: System Design & Scalability, Language & Framework Core, Database & Concurrency, Architecture & Design Patterns, Resilience & Security.
- **Format**: conceptual, code reading, live coding sandbox, scenario, debugging, system design whiteboard, behavioral STAR.
- **Difficulty**: calibrated scale 1–5 (Adaptive dynamic stepping).
- **Language**: Vietnamese, English (Bilingual prompt & rubric evaluation).

## Question lifecycle

`DRAFT -> IN_REVIEW -> APPROVED -> ACTIVE -> RETIRED`.

AI-generated question chỉ được dùng runtime nếu qua automated validation; muốn vào question bank chuẩn phải có reviewer approval.

## Quality rules

- Có expected concepts và rubric reference.
- Không có đáp án phụ thuộc thông tin lỗi thời nếu thiếu version/date.
- Không chứa dữ liệu cá nhân hoặc nội dung sao chép không rõ quyền.
- Tránh câu đố mẹo không liên quan năng lực công việc.
- Phân bố difficulty và competency theo blueprint, không random thuần túy.
