# Synthetic sample data

All files in this directory are synthetic, non-production fixtures for contract discussion, demos, and test seeding. Domains use `.example.test`; identifiers are deterministic and must never be treated as real credentials or users.

The samples demonstrate version pinning, bilingual content, evidence-based evaluation, event correlation, and AI adversarial expectations. They are illustrative contracts; shared Zod/OpenAPI/event schemas remain authoritative after implementation.

Validate all JSON before use. Do not import it into production. Do not replace fixtures with copied candidate answers, interview-bank leaks, or personal data.
